## ЧАСТЬ 4 — 🔴 ЖИВОЙ ПРОГОН IG (критично, делать РАНО — тут риск)

Это единственное, что не гоняли. Делай на **одноразовом/тест-аккаунте**, не на боевом.

1. Аккаунт с **валидными свежими cookies** (экспортни из браузера, где залогинен) + **рабочий прокси**.
2. В **Orchestrator**: «warm up @testaccount for 2 minutes» → Approve & Fan-Out (таргет — этот аккаунт).
3. Смотри **терминал воркера** (шаг 4): должно быть `[run_instagram_task] task_id=...`, запуск Chromium, без трейсбеков.
4. На странице **Activity** аккаунт должен появиться как «running», потом в **Tasks** → completed.
5. Если упало — открой задачу в **Tasks**, там `error_log` с причиной.

**Вероятные грабли и куда смотреть:**
| Симптом | Причина / куда копать |
|---|---|
| Task сразу FAILED, `low_trust_score` | прокси не пингуется → проверь прокси (host/port/login/pass) |
| Браузер стартует, но не логинится | cookies протухли → возьми свежие |
| `checkpoint_required` | IG бросил челлендж → реши вручную в IG, потом смени статус аккаунта на active |
| Task висит RUNNING | воркер/beat не запущены, или гейт ждёт слот — проверь логи воркера |
| `UnsafePathError` при upload | путь к файлу вне `MEDIA_ROOT` — загружай через /media |
| Chromium не стартует | смотри трейс в логе воркера (флаги/прокси-расширение) |

> Если живой прогон не заведётся за разумное время — для созвона можно показать
> весь флоу (план → fan-out → задачи), а реальный браузерный прогон отложить.
> Так и скажи кенту: «движок есть, отлаживаем последний слой».

## ЧАСТЬ 5 — Доступ кенту (ngrok + Vercel)

1. `ngrok http 8000` (лучше со static-доменом, чтоб URL не менялся) → скопируй `https://...`.
2. Vercel → проект фронта → Settings → Env → `NEXT_PUBLIC_API_URL = <ngrok https URL>` → **Redeploy**.
3. Открой Vercel-ссылку **с телефона по мобильному интернету** (не по своему Wi-Fi!) — проверь, что
   логин/дашборд работают (это эмулирует кента).
4. Дай ссылку кенту, пусть зарегается. Ты как админ выдай ему агентов/тариф в /admin.

Проверка перед тем как звать кента:
- [ ] Vercel-ссылка открывается с чужой сети.
- [ ] Регистрация/логин проходят (значит фронт достучался до бэка через ngrok).
- [ ] В Network нет CORS/mixed-content ошибок.
